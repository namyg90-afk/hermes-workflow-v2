# 노코드 자동 기반 업무프로세스 자동화 과정 V2

자연어로 업무를 지시하고, Hermes가 실행·기록하며, 필요한 작업을 GPT·Gemini·Claude에 연결하는 실습 자료입니다. 일차 구분 없이 준비 → 설치 → 연결 → 실습 → 반복 자동화 순서로 진행합니다.

검토일: **2026-09-12 (Asia/Seoul)**. 명령과 모델 목록은 설치 버전 및 계정에 따라 달라질 수 있습니다.

## 환경 점검

저장소를 내려받은 뒤 PowerShell에서 실행합니다. 아래 스크립트는 설치·설정 변경·네트워크 요청 없이 명령 가용성과 Python 패키지만 확인합니다. 인증 파일과 환경변수 값은 읽지 않습니다.

```powershell
& .\scripts\check-environment.ps1
```

## 교육 자료의 범위

이 저장소에는 교육용 문서와 읽기 전용 점검 스크립트만 있습니다. 운영 중인 봇 설정, 토큰, 비밀번호, 대화 기록, 연구 데이터는 포함하지 않습니다. 설치 프로그램은 각 프로젝트의 공식 배포처를 사용합니다. 교육 과정이 특정 유료 구독이나 API 사용량을 포함하지는 않습니다.

다른 PC에서 새로 설치하는 절차와 기존 PC에서 확인된 구성을 구별해 읽어주세요. 특히 **설치됨**, **로그인됨**, **모델 목록 조회됨**, **실제 추론 성공**은 서로 다른 상태입니다.
